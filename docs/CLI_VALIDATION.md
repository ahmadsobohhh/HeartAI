## Geometry and unit conventions

1. Extract each verified class into a binary mask and crop only for memory efficiency. Incorporate the crop offset into its affine.
2. Pad by one zero voxel, run [scikit-image marching cubes](https://scikit-image.org/docs/0.24.x/api/skimage.measure.html#skimage.measure.marching_cubes) at 0.5, and remove the padding offset from vertex coordinates.
3. Apply the full affine to get patient/world RAS coordinates in millimeters. Reflected affines also require corrected face winding, handled by Trimesh's transform.
4. Export STL vertices in RAS mm. STL does not encode units; import as millimeters.
5. Export GLB in meters, per the [glTF specification](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#coordinate-system-and-units), with `(x,y,z) = (R,S,-A)/1000`. The conversion matrix is recorded in each case manifest. The patient origin is retained consistently across files. Use the inverse matrix to recover RAS mm.

No smoothing, decimation, removal of components, or independent centering is applied. The combined GLB retains separate named geometry objects using [Trimesh's GLB export](https://trimesh.org/trimesh.exchange.gltf.html).

Volume uses `voxel_count * abs(det(affine[:3,:3]))`, divided by 1000 for mL. This is the spacing product for orthogonal grids and remains correct under shear. Centroids are the mean of voxel-center coordinates. Bounds include voxel-cell extents on all three world axes, not just center extrema. Measurements are computed from segmentation voxels, never from marching-cubes enclosed volume.

## Checks and limitations

All seven exported GLBs and STLs were reopened. Coordinates and triangles were finite/nonempty; bounds matched the expected export scale; surfaces were watertight and consistently wound. The myocardium export was rendered using Python and visually inspected. A full-case check independently recalculated every reported volume from the saved NIfTI.

Synthetic tests cover anisotropic spacing, reflections, rotation/shear, world translation, a single voxel, empty masks, label-map consistency, separate components, export units, case serialization and failure handling. No medical data or checkpoint is required for normal tests. The official transform/inversion integration test also passes.

The aorta touches the inferior scan boundary: the zero padding closes the visible portion, not the complete anatomical vessel. The left-ventricle prediction contains **three disconnected components**; all are retained, including an outlying region that expands the superior/inferior bounds to 180 mm. This is a prediction limitation, not a normal anatomical dimension. Other cardiac masks each have one 26-connected component.

The native-grid surfaces remain visibly stepped because the model inferred at 3 mm. Surface integrity does not establish anatomical accuracy. No clinical evaluation, GPU run, frontend/backend, or training was performed. The in-process pipeline is currently a serial CLI workflow.
